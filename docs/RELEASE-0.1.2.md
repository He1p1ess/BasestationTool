# Basestation Tool v0.1.2

## Changes
- Redesigned the desktop interface with a custom draggable title bar, window controls, icons, a purple dark theme and a white/pink light theme.
- Simplified the top toolbar and removed the duplicate application heading.
- Automatically size the station table for up to five visible rows; additional stations scroll.
- Grow the window when more room is needed while preserving manual resizing. Logs fill the remaining space.
- Run On, Standby, Sleep and Identify directly for the displayed selection. Channel changes still require confirmation.
- Default to English for new configurations while preserving existing language preferences.

## Downloads
- Windows x64: portable EXE and per-user MSI installer.
- Linux x86-64: Debian/Ubuntu DEB and AppImage.
- SHA256SUMS.txt contains checksums for all four packages.

Windows packages are unsigned. Linux packages are cross-compiled; Linux desktop and Bluetooth runtime testing has not been performed for this release.
